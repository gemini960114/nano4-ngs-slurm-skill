# 範例 4：結果解讀與報告 —— 讓 AI 整理圖文報告，並換上自己的研究資料

跑完生醫分析後，最花時間的往往是翻找各個日誌檔（`*.out`）、統計數據與圖表產物來撰寫實驗紀錄或結案報告。本單元示範如何利用 **`nano4-ngs-report`** 技能，讓 AI 自動整理出結構化的 **Markdown (`.md`)** 與 **可列印 PDF 的獨立 HTML 圖文報告 (`.html`)**，並說明如何將整套做法換上您自己的研究資料。

| 步驟 | 內容 | 預估時間 |
| :--- | :--- | :---: |
| **第 1 步** | [讓 AI 讀取分析結果，自動整理成圖文報告 (`tutorial/report01`)](#第-1-步讓-ai-讀取分析結果自動整理成圖文報告) | 10 分鐘 |
| **第 2 步** | [將 `.html` 圖文報告另存為 PDF](#第-2-步將-html-圖文報告另存為-pdf) | 2 分鐘 |
| **第 3 步** | [換上自己的定序資料與研究問題](#第-3-步換上自己的定序資料與研究問題) | 5 分鐘 |

---

## 第 1 步：讓 AI 讀取分析結果自動整理成圖文報告

### 📋 請複製以下指令貼給 AI Agent：

```text
請啟用 nano4-ngs-report 技能，掃描 tutorial/ 與 qc/ 下的所有 Slurm 腳本、執行日誌（*.out / *.err）與分析產出檔案，為我撰寫一份結合「Runbook 操作手冊」與「生醫 Methods & Results 數據解讀」的完整分析報告，並使用技能內建的轉換腳本同步輸出 .md 與單一獨立 .html 報告至 tutorial/report01/。
```

- **AI 會自動幫您完成**：
  1. **證據盤點（不捏造數據）**：自動讀取實際的 Job ID、CPU/記憶體耗用、執行秒數、樣本數與篩選前後 Reads 數。
  2. **繪製架構圖、數據圖與表格**：自動生成 Mermaid 管線流程圖、各樣本數據比較圖（PNG）、環境模組版本表、統計結果比較表與 `.qzv` 圖表導讀。
  3. **一鍵雙格式輸出**：同時產出 `.md` 原稿與內嵌樣式表的單一自包含 `.html` 網頁報告。

---

## 第 2 步：將 html 圖文報告另存為 PDF

1. 在 Antigravity 左側檔案總管展開 `tutorial/report01/`。
2. 在產出的 **`.html` 報告檔** 上按**右鍵 → Download...** 下載至個人電腦。
3. 在電腦上雙擊該 `.html` 檔（以 Chrome / Edge / Safari 開啟）。
4. 點擊網頁右上角的 **「🖨️ 列印 / 另存為 PDF」** 按鈕（或按 `Ctrl + P` / `Cmd + P`），目標選擇 **「另存為 PDF (Save as PDF)」**，即可輸出一份自動隱藏導覽列、防表格斷頁的正式 PDF 報告。

> [!NOTE]
> 報告中的流程圖由網路載入 Mermaid.js 繪製，請在有網路的電腦開啟後再列印；離線時流程圖會顯示為原始程式碼，其餘文字、表格與圖片不受影響。

---

## 第 3 步：換上自己的定序資料與研究問題

學會這套「**官方文件 ➔ 自訂 Skill ➔ 確認後派送與定時監控 ➔ 自動整理圖文報告**」的工作流後，當您回到實驗室面對自己的研究問題（例如 RNA-seq、WES/WGS 變異偵測、單細胞分析或宏基因體組裝）時，只需照以下 **3 個步驟** 操作：

| 階段 | 您需要做的事 | 如何跟 AI 協同？ |
| :--- | :--- | :--- |
| **1. 放入您的資料與規則** | 在 `/work/$USER/` 建立新專案資料夾，把本研究室的 FASTQ/BAM 資料放進去，並複製本教材的 `AGENTS.md` 與 `.agents/skills/` | 開啟該資料夾後，AI 已經自動具備「Nano4 Slurm 排程規則」與「圖文報告整理」兩大基本功 |
| **2. 針對新工具擴充 Skill** | 查詢國網 Nano4 上該分析工具的模組（`module spider <軟體名>`）或準備好 Apptainer `.sif` 容器，或貼給 AI 該軟體的官方手冊網址 | 對 AI 說：<br>「*請讀取這份分析流程文件，結合我們專案的 `nano4-ngs-slurm` 規則，幫我設計一套針對 `/work/$USER/my_data/` 的分析管線，送出前先跟我說明每一步的參數，確認後再送出並每 5 分鐘檢查狀態。*」 |
| **3. 判讀結果與產出報告** | 由您（研究人員）運用領域專業檢查關鍵品管指標與統計圖表是否合理 | 對 AI 說：<br>「*請用 `nano4-ngs-report` 技能讀取這次的分析日誌與結果表，幫我整理成一份包含 Methods 與 Results 解讀的 HTML 圖文報告。*」 |

> [!NOTE]
> 內建的 `nano4-ngs-report` 也是用範例 2 的方法請 AI 產生，再由講師人工修訂而成；您可以用同樣方式，為自己的分析工具建立專屬 Skill。
